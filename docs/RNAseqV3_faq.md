
**Q1. What is the maximum size of uploading data?**\
100Mb

**Q2. Can I use FPKM and TPM data as input matrix?**\
No. The raw count matrix is required, which is usually obtained from 'RSEM', 'HTSeq' or 'featureCounts' program.

**Q3. Can I use this App for batch correction?**\
Yes, you can include a batch column. It works only if your design is paired. Please contact CAB scientists to customize your analysis.

**Q4. Can I use *RSEM_count*.txt from CAB AutoMapper as input?**\
Yes.
You could use any other raw count table downloaded from <a herf="https://www.ncbi.nlm.nih.gov/geo/" target="_blank">GEO</a>, or generated by other software like <a href="https://htseq.readthedocs.io/" target="_blank">HT-seq</a>, <a href="https://pubmed.ncbi.nlm.nih.gov/24227677/" target="_blank">featureCount</a> etc.

**Q5. How to use Microsoft Excel generate a sample_metadata tsv file ?**\
Input your sample information. The first row must include column name of three requried columns (ID, NEWNAME and GROUP),
after that each row contains the above information for each sample.
Then File--> Save As -->choose Text (Tab delimited)(*.txt)

**Q6. Can I include non-coding genes and pseudogenes in differential analysis?**\
Yes. In Step1.Input, you can uncheck option [Exclude non-coding genes and pseudogenes].

**Q7. Does pipeline filter out lowly expressed genes prior to DE analysis?**\
Yes. To ensure that the quality results are obtained, genes with very low expression values are also removed.
Only include genes with raw read count > 10 in at least one sample group involved in pairwise comparison.

**Q8. Does this pipeline generate FPKM and TPM table?**\
No. FPKM, TPM normalizations require gene length(species, gene annotation etc.),which is independent of DE analysis.
We may provide a conversion tool for this purpose in the future.
